# Yield Tracker frontend

React and TypeScript app for the [Yield Tracker](../README.md) project. It lists harvests, adds new rows, and shows yield totals from the API.

See the root README for database setup, `VITE_API_URL`, and how to start the API. The dev server is `http://localhost:5173`.

```powershell
npm install
npm run dev
npm run build
npm run preview
npm run lint
```
